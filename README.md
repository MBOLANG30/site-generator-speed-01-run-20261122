# site-generator-speed-01-run-20261122

Faster drop-in for makefun-site 1.0.0

A from-scratch, dependency-free reimplementation of makefun-site 1.0.0's
`build()`: it returns exactly the same output tree for every input, but
faster. `solve.js` exports `run(input)`; `main.ts` reads the cases from
`/input/cases.json`, answers each with `run`, and writes `/output/answers.json`.

## Run it

```sh
node main.ts
```

Node 22 or later, no dependencies, no network.
